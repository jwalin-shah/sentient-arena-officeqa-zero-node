# Sentient Arena OfficeQA Strict Grounded Harness

Local-first harness for OfficeQA with strict grounded evaluation, stage traces, and reproducible splits.

## Core idea
- Real grounded eval requires real source docs.
- Strict mode disables silent parse/extraction fallbacks.
- Every run emits structured traces + failure diagnostics.

```bash

  --baseline-config config/openhands_cerebras_officeqa_base.yaml \

  --smoke-dataset data/splits/smoke.jsonl \
```

## Strict grounded contracts
In strict mode (`pipeline.strict_eval_mode: true`):
- No parse fallback.
- No extraction fallback.
- Missing corpus source file => hard retrieval failure.
- Missing `evidence_rows` in model response => hard extraction failure.

Required solver JSON keys:
- `final_answer`
- `reasoning_summary`
- `confidence`
- `evidence_rows[]` with:
  - `source_file, table_or_section, row_label, column_label, raw_value, unit, matched_snippet`

Strict row gates:
- `row_presence_gate`: minimum required rows by operation
  - `lookup=1`, `difference=2`, `ratio=2`, `average=2` (configurable)
- `row_grounding_gate`: kept rows must pass grounding checks
- Optional/noisy rows may be dropped; strict depends on required grounded rows, not extra rows.

Scoring is dual:
- `numeric_accuracy_1pct`: answer-only correctness at 1% tolerance
- `strict_grounded_accuracy`: numeric correctness plus schema-valid grounded evidence

## Run artifacts
Each run writes:
- `examples.jsonl`
- `summary.json`
- `config.snapshot.json`
- `trace_report.json`
- `trace_report.md`

`summary.json` now includes run telemetry:
- `telemetry.attempts_total`
- `telemetry.llm_calls_total`
- `telemetry.parse_calls_total`
- `telemetry.solve_calls_total`
- `telemetry.solve_prompt_chunks_total`
- `telemetry.solve_prompt_chars_total`

This is the quickest way to explain slow/frozen-looking runs: too many attempts/calls or too much solve prompt context.

## Config knobs
- `pipeline.parse_mode: rule_based|llm_structured`
- `pipeline.strict_eval_mode: true|false`
- `pipeline.max_attempts: 3`
- `pipeline.retry_failed_stages_only: true|false`
- `pipeline.stop_on_strict_pass: true|false`
- `decision.final_gate: strict_plus_numeric`
- `backend.openhands.structured_output: true|false`
- `backend.openhands.parse_schema_name`
- `backend.openhands.solve_schema_name`
- `backend.openhands.solve_max_output_tokens`
- `corpus.root_dir`
- `corpus.format: transformed_txt|parsed_json|pdf`
- `corpus.max_files_from_year_fallback`
- `corpus.max_chunks_per_file`
- `corpus.max_chars_per_chunk`
- `trace.review_enabled: true|false`

CLI overrides:
- `python3 scripts/run_eval.py --max-attempts 3 --final-gate strict_plus_numeric ...`
