## Research Recommendations

1. First is **AI self-improvement / evolution**: tools like GEPA/GEPA+, optimize-anything, Evolver, the integrated systems in things like Hermes-Agent, and our own EvoSkill. These are all tools that have been created, most of them just in the past month, that promise to automate the development of AI systems.
How well do they work? Are they all the same? Are some algorithms better than others? How do you guide the algorithm for something that is industry- or dataset-specific? Can you make your agent harness learn skills automatically without the user ever doing anything by themselves? These are all completely new and unexplored questions.
2. Second direction is **Transfer Learning** or Generalizability: if you are able to develop an amazing skill for OfficeQA, how good is it on other benchmarks with a similar setup, and vice versa? It may be that a generalizable skill generation solution does not get 1st place on the OfficeQA leaderboard, but it will be useful to all people in the world! Also, how are you able to adapt skills across benchmarks or retrieve similar skills efficiently, so that a small collection of hyper-optimized well-written skills or agents may actually be all you need to solve any other problem.
3. Third direction is **Automated Evaluation**: evolution algorithms require some signal for iteration, but day-to-day usage patterns do not look precisely like benchmarks. Is it possible to create benchmarks completely automatically, pull together tool requirements, prompt specifications, and more, so that you are able to create that feedback for the evolution algorithms without any human intervention?

All 3 of these directions are toward one purpose: automating the AI engineering process and enabling each person in the world to build AI that is useful specifically for them and their tasks, and not tied to a static benchmark.
